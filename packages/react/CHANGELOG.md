# @skeletwin/react

## 1.0.0

Initial release.

- Generate skeleton shapes from rendered text, media, form controls, and custom components.
- Preserve child state and update shapes when content or layout changes.
- Support shimmer, pulse, static placeholders, CSS themes, and detection overrides.
- Provide accessible loading states, reduced-motion support, and server-rendering compatibility.
- Publish ESM and CommonJS builds with TypeScript declarations and a separate stylesheet.
